OPTIONAL OPENAI API

正在检查可选 AI 设置。

默认关闭
只有你显式设置 ENABLE_AI_SUMMARY=1 并配置 API Key 后，才会调用 OpenAI Platform API；自动任务还需另行设置 AUTO_SUMMARY_ENABLED=1。
发送内容与费用
播客名、单集名、节目简介/时间轴（最多 120,000 字符）以及你的生成操作会发送给 OpenAI。请求不提供 Shell、网页或本机文件工具，设置 store:false，但仍受你的 OpenAI API 数据控制与按量计费规则约束。
整期音频
深度模式需单独启用；会分段上传整期音频并可能产生费用。受保护的机核音频默认拒绝，且只应处理你有权上传的内容。
